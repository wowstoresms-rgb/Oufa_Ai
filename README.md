# Oufa_Ai STUDIO

استوديو ويب لمعالجة الملفات والميديا. يعمل محلياً أو على Render باستخدام Docker.

## التشغيل محلياً
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
افتح `http://localhost:10000`.

## النشر على Render
1. ارفع المجلد إلى مستودع GitHub.
2. من Render اختر **New > Blueprint** واربط المستودع الذي يحتوي `render.yaml`، أو أنشئ Web Service واختر Docker.
3. انشر الخدمة. المنفذ الافتراضي 10000.

## مفاتيح Gemini
أدخل مفتاح Google Gemini من زر «حسابات AI». يحفظ المفتاح في LocalStorage بالمتصفح ويرسل إلى الخادم عند طلب المهمة فقط. لا تضع المفتاح في المستودع ولا تشارك جهازك/جلسة المتصفح مع الآخرين. استخدم مفتاحاً مخصصاً وراجع حدود Google المجانية.

## المهارات
ضع ملفات Python الموثوقة (`.py`) داخل `skills/`. تظهر في الواجهة ويمكن تشغيلها بطلب POST إلى `/api/skills/<name>`؛ يجب أن تصدّر الدالة `run(input_data)`.

## ملاحظات مهمة
- المشروع أداة بداية قابلة للتطوير، وليس خدمة سحابية مضمونة المجانية بلا حدود. خطة Render المجانية والموارد وحدود مزودي الخدمات قد تتغير، كما أن معالجة الفيديو وLibreOffice تستهلك ذاكرة ووقتاً وقد تتجاوز موارد الخطة المجانية.
- Pollinations.ai وEdge-TTS يعتمدان على خدمات خارجية وقد تتغير إتاحتهما أو شروطهما.
- لا ترفع ملفات حساسة أو غير موثوقة إلى خادم عام. أضف مصادقة وحدود استخدام وتخزيناً خاصاً قبل الاستخدام الإنتاجي.
- ملفات المستخدم تحفظ مؤقتاً في `uploads/` والنتائج في `outputs/`. في Render قد يكون نظام الملفات مؤقتاً ويُمسح عند إعادة التشغيل/النشر.
- الكاميرا تتطلب HTTPS أو localhost وإذن المستخدم.
